# muse-video-prompt-director

面向 Muse Video、Seedance 2.0 Mini 和 MiniMax H3 Max 的中文视频导演提示词技能。根据目标模型、生成入口与5／10／15秒目标分段，组织可独立复制的提示词。

## 能力

- 区分文生视频、图生视频与参考生视频，说明素材用途与首帧关系。
- 将核心事件、镜头、动作、表演、声音及收尾组织成连续时间轴。
- 为长视频规划分段，分别记录生成时长、最终取用区间及全片累计时间。
- 保留人物、服装、道具与空间连续性，检查每段的观看价值与情绪推进。
- 根据具体入口核实可选时长、音频与参考能力；5／10／15秒是目标长度，不代表所有模型均支持。

完整规则见 [SKILL.md](SKILL.md)。本项目为规则型技能，不包含视频生成程序或API客户端；实际生成按所用工具的能力执行。

此版本在已有技能基础上增加了 Seedance 2.0 Mini、MiniMax H3 Max 提示词规划和 5 秒目标分段支持；也支持按 10 或 15 秒目标长度规划。具体修改范围与来源边界见[来源记录](PROVENANCE.md)。

## 安装

在尚未安装此技能的机器上，将仓库克隆到技能目录。例如使用 Codex 默认技能目录：

```powershell
git clone https://github.com/neozhou2009/muse-video-prompt-director.git "$env:USERPROFILE/.codex/skills/muse-video-prompt-director"
```

仓库为私有时，先用有访问权限的GitHub账号登录。若已有同名技能目录，先比较并备份现有内容，再决定如何更新，避免覆盖个人修改。安装后按所用客户端的方式重新加载技能。

## 使用示例

```text
$muse-video-prompt-director
为30秒哥特悬疑短片制作中文提示词。
目标为Seedance 2.0 Mini，入口Artlist网页Unlimited，目标每段5秒。
竖屏9:16，无配乐，保留环境声。列出分段表，再给每段可独立复制的完整提示词。
未能核实的入口能力标记待验证，不提交生成。
```

图像参考示例：

```text
$muse-video-prompt-director
制作10秒视频提示词。图片1只锁人物身份，图片2只作场景参考，均不锁首帧。
明确摄影机运动、主体动作与结束状态，不添加对白。
```

示例中的模型参数仍需按实际入口核实，不能以示例代替能力验证。
